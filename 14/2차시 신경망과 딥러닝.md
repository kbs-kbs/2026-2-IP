# 2차시 신경망과 딥러닝

## 1. 신경망

- 영상처리에 쓰는 신경망은 훈련 패턴 집합을 잇따라 제시해 판정 함수의 계수를 적응적으로 발전시키는 수단이다.
- 입력을 분류하기 위해 입력이 네트워크를 통해 매핑되는 방정식(역전파 방정식, 심층 신경망)을 개발한다.

### 1.1 발전 과정

| 시기 | 내용 |
|---|---|
| 1950~1960년 | Rosenblatt의 학습 기계. 선형 분리가 가능한 대상이 유한 반복 내 수렴함을 증명, 퍼셉트론 개념 |
| 1960~1980년 | 전문가 시스템과 1차 AI 붐, 다층 퍼셉트론 알고리즘 개발 |
| 1980~2000년 | 2차 AI 붐과 신경망의 암흑기 |
| 2000~2010년 | 통계 기반 머신러닝과 분산 처리 기술 발전 |
| 2010년 이후 | 심층 신경망 기반 이미지 인식 성능 향상, 3차 AI 붐 |

- 2012년 토론토 대학 팀의 딥러닝 이미지 인식 프로그램이 ILSVRC 2012에서 1위, 2015년에는 사람의 오류율(약 5%) 아래로 내려간 프로그램이 등장했다.
- 거대한 이미지·메타데이터 데이터베이스가 인식 엔진 발전을 뒷받침했다.
- 지도 학습 데이터의 다양성을 높이기 위한 전처리를 수행하고, 합성곱 신경망(CNN) 또는 그 변형을 쓴다. R-CNN은 특정 영역을 설정해 사물을 인식하는 CNN으로, 고전적 사물 인식의 영역 자르기(cropping) 전처리를 포함한다.

## 2. 퍼셉트론

### 2.1 단순 퍼셉트론

- 입력층과 출력층만으로 구성되며, 각 입력 $x_i$에 가중치 $w_i$를 곱해 합한 뒤 임계값으로 판정한다.

| 한계 | 내용 |
|---|---|
| 선형 분리 불가 | 데이터가 선형 분리 불가능하면 퍼셉트론 학습 적용 불가 |
| 수렴 속도 | 선형 분리 가능해도 평면 분리 상태가 되는 데 오래 걸릴 수 있음 |

- **퍼셉트론 수렴 정리**: 긍정·부정 예에서 학습 데이터가 선형 분리 가능하면 반드시 유한 횟수 반복으로 평면 분리 상태를 찾을 수 있다.

| 논리 함수 | 선형 분리 |
|---|---|
| AND | 가능 |
| OR | 가능 |
| XOR | 불가능 |

- XOR은 직선 하나로 0과 1을 나눌 수 없어 단순 퍼셉트론의 대표적 한계다.

### 2.2 다층 퍼셉트론(MLP)

- 단순 퍼셉트론을 여러 번 연결해 비선형으로 보이는 분포를 선형 분리 가능한 분포로 변환한다.
- 순방향으로 계층마다 출력을 계산한 뒤 **오차 역전파법**으로 출력층에서 역방향으로 가중치를 갱신한다.
- 학습 전제: 네트워크 구조와 정답 데이터가 주어져야 한다. 정답과의 조율은 최소 제곱 오차 등의 오차 함수를 만들고 경사 하강법으로 최소화한다.

## 3. 다층 순방향 신경망

- 퍼셉트론의 중간층(은닉층)을 여러 개 사용한 신경망이다.
- 노드 출력에 임계치를 적용해 $+1$ 또는 $-1$에 수렴하도록 하고, 활성화 함수로 임계치보다 큰 값을 출력한다.
- 예: 시그모이드 함수

$$
h_j(I_j) = \frac{1}{1 + e^{-(I_j + \theta_j)/\theta_0}}
$$

| 활성화 함수 | 특징 |
|---|---|
| 시그모이드 | 0~1 출력, $\theta_0$가 작을수록 급격한 천이(계단에 가까움) |
| tanh | $-1$~$1$ 출력, 0 중심 |
| ReLU | 음수는 0, 양수는 그대로. 기울기 소실 완화 |

## 4. 역전파

### 4.1 목표

- 훈련 패턴을 사용해 모든 가중치를 조정하는 규칙을 찾는 것이다. 각 가중치를 손실의 기울기 반대 방향으로 갱신한다.

$$
w = w - \alpha\frac{\partial L}{\partial w}
$$

- $\alpha$는 학습률, $L_i$는 손실, $a_i$는 활성화 함수를 통한 출력, $z_i$는 $i$번째 층의 출력이다.

### 4.2 출력층 가중치 조절

$$
L_1 = \frac{1}{2}\left(y_1 - a_1^{(2)}\right)^2
$$
$$
a_1^{(2)} = \mathrm{activation}\left(z_1^{(2)}\right), \qquad z_1^{(2)} = w_{11}^{(1)}a_1^{(1)} + w_{21}^{(1)}a_2^{(1)} + w_{31}^{(1)}a_3^{(1)}
$$
$$
\frac{\partial L_1}{\partial w_{i1}^{(1)}} = \frac{\partial L}{\partial a_1^{(2)}}\cdot\frac{\partial a_1^{(2)}}{\partial z_1^{(2)}}\cdot\frac{\partial z_1^{(2)}}{\partial w_{i1}^{(1)}} = \beta_1^{(2)} a_i^{(1)}
$$

- 같은 방식으로 두 번째 출력의 가중치도 $\partial L_2/\partial w_{i2}^{(1)} = \beta_2^{(2)}a_i^{(1)}$로 구한다.
- $\beta_i^{(2)}$는 출력층 노드 $i$의 오차 신호(델타)로, 오차에 활성화 함수의 미분을 곱한 값이다.

### 4.3 은닉층 가중치 조절

$$
\frac{\partial L}{\partial w_{11}^{(0)}} = \frac{\partial L}{\partial a_1^{(1)}}\cdot\frac{\partial a_1^{(1)}}{\partial z_1^{(1)}}\cdot\frac{\partial z_1^{(1)}}{\partial w_{11}^{(0)}}
= \left(\frac{\partial L_1}{\partial a_1^{(1)}} + \frac{\partial L_2}{\partial a_1^{(1)}}\right)\frac{\partial a_1^{(1)}}{\partial z_1^{(1)}}\frac{\partial z_1^{(1)}}{\partial w_{11}^{(0)}}
= \left(\beta_1^{(2)}w_{11}^{(1)} + \beta_2^{(2)}w_{12}^{(1)}\right)\frac{\partial a_1^{(1)}}{\partial z_1^{(1)}}\frac{\partial z_1^{(1)}}{\partial w_{11}^{(0)}}
$$

- 은닉층 노드의 오차는 **연결된 모든 출력 노드의 오차를 가중치로 역전파해 합한 것**이다. 이 연쇄가 은닉층이 여러 개여도 반복된다.
- 역전파로 선형 분리가 불가능한 XOR도 분리할 수 있는 네트워크를 학습할 수 있다.

## 5. 심층 컨볼루션 신경망(CNN)

### 5.1 기본 구조

- 동물 시각 피질 구조에서 영감을 받은 모델이다. 특징을 추출하는 합성곱층과 정보를 압축하는 풀링층을 반복하고, 후반에 다층 퍼셉트론(완전 연결층)을 둔다.

```
Convolution+ReLU → Pooling → Convolution+ReLU → Pooling → Fully Connected → Fully Connected → Output
```

### 5.2 각 단계

**(1) 패딩**

- 합성곱 결과 행렬의 크기를 조정하기 위해 입력 배열 둘레를 0으로 채우는 연산이다. 특징맵이 작아지는 것을 막는다.

**(2) 합성곱**

- $3 \times 3$ 필터를 입력 위로 이동하며 곱의 합을 계산해 특징맵을 만든다. 필터 계수(가중치)는 학습으로 결정된다.

**(3) 풀링**

- 일정 크기 블록을 하나의 대표값으로 대체해 특징맵을 압축하고 특정 데이터를 강조한다.

| 풀링 | 대표값 |
|---|---|
| 최대 풀링(Max) | 블록의 최댓값 |
| 평균 풀링(Average) | 블록의 평균 |

- 예: $4 \times 4$ 활성화 맵을 $2 \times 2$ 블록으로 최대 풀링하면 $2 \times 2$가 된다.

**(4) Flatten**

- $(a,b)$ 행렬을 $a \times b$ 길이의 열 벡터로 바꾼다. ReLU를 거친 뒤 Softmax의 입력으로 전달한다.

**(5) Softmax**

- 수치 출력을 확률로 변환한다.

$$
\mathrm{softmax}(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}
$$

- 출력 수치가 $[0.1, 0.2, 0.7]$처럼 합이 1인 확률로 변환된다. 가장 큰 수치의 클래스가 가장 높은 확률을 갖는다.

### 5.3 MNIST 숫자 인식 예

```
입력 28×28×1
→ Conv_1 (5×5, valid padding) → 24×24×n1
→ Max-Pooling (2×2) → 12×12×n1
→ Conv_2 (5×5, valid padding) → 8×8×n2
→ Max-Pooling (2×2) → 4×4×n2
→ fc_3 (Fully Connected, ReLU)
→ fc_4 (Fully Connected, dropout)
→ 출력 0~9
```

- 합성곱과 풀링을 반복할수록 공간 크기는 줄고 채널 수는 늘어나, 위치 정보보다 의미 특징이 압축된다.

## 6. 추가 구현 세부 사항

### 6.1 보편성 근사 정리

- 임의의 복잡한 판단 함수는 단일 은닉층이 있는 연속 순방향 신경망으로 근사할 수 있다.
- 그럼에도 심층 신경망이 단일 은닉층 신경망보다 실제 성능이 우수하다. 같은 표현력을 훨씬 적은 노드로 달성하고, 계층적 특징을 학습하기 때문이다.

### 6.2 심층 신경망의 문제와 대응

| 문제 | 원인 | 대응 |
|---|---|---|
| 기울기 소실 | 계층이 많을수록 역전파 기울기가 너무 작아져 소실 | 패딩 사용, 활성화 함수를 시그모이드에서 ReLU로 대체, 배치 정규화 |
| 과적합 | 훈련 집합에는 잘 맞지만 새 데이터에서 인식률이 크게 떨어짐 | 드롭아웃(연결된 노드 일부를 임의로 삭제), 데이터 증강, 조기 종료 |

- 드롭아웃은 학습 중 노드를 무작위로 끄면서 특정 노드에 과도하게 의존하는 것을 막는다.

## 핵심 정리

- 신경망은 훈련 패턴으로 판정 함수 계수를 적응시키는 수단이고, 단순 퍼셉트론은 선형 분리 문제만 풀며 XOR은 불가능하다.
- 다층 퍼셉트론은 은닉층과 역전파·경사 하강법으로 비선형 문제를 풀고, 은닉층 오차는 출력 노드 오차의 가중 합으로 전파된다.
- CNN은 합성곱+ReLU와 풀링을 반복해 특징을 추출하고, Flatten 후 완전 연결층과 Softmax로 분류한다.
- 기울기 소실은 ReLU·패딩으로, 과적합은 드롭아웃으로 완화한다.
