# 1차시 경계 전처리

## 1. 경계선 추적

- 경계점을 시계 또는 반시계 방향으로 정렬해 정렬된 점의 시퀀스로 경계선을 추적한다.
- 객체와 배경을 1, 0으로 레이블링하고, 객체가 영상 경계에 붙지 않도록 경계를 0으로 패딩한다.

### 1.1 추적 알고리즘

1. 시작점 $b_0$를 영상의 1로 레이블링된 좌측 상단 점으로 잡고 $b_0$의 왼쪽 배경을 $c_0$로 표시한다.
2. $c_0$에서 시작해 시계 방향으로 전진하며 $b_0$의 8-이웃을 조사한다.
3. 값이 1인 첫 번째 이웃을 $b_1$으로 표시하고, $b_1$ 바로 직전의 배경점을 $c_1$으로 표시한다.
4. $b = b_0$, $c = c_0$로 두고 시계 방향으로 전진해 $b$의 8-이웃 중 레이블 1인 첫 이웃을 찾는다. 시작점으로 돌아오면 종료한다.

- 추적은 8-이웃 연결을 쓰므로 대각선으로 이어진 경계도 하나의 경계로 따라간다. 경계를 0으로 패딩하지 않으면 객체가 영상 끝에 닿았을 때 추적이 끊긴다.

## 2. 체인 코드

- 경계를 시계·반시계 방향으로 따라가며 각 픽셀 쌍을 잇는 세그먼트에 방향(0~7)을 할당해 만든다.

| 문제 | 해결책 |
|---|---|
| 코드가 너무 길어짐 | 경계를 재샘플링(다운샘플링)해 길이 단축 |
| 시작점에 의존 | 표현 문자열을 가장 작은 정수로 정규화 |

- 8방향 체인 코드는 0=동, 1=북동, 2=북, …, 7=남동의 방향 번호를 쓴다.
- 중첩된 리샘플링 그리드를 쓰면 경계 길이를 줄이면서 모양의 큰 특징을 유지한다.

## 3. 최단 둘레 다각형을 이용한 다각형 근사화

- 경계를 다각형으로 근사하면 변(또는 정점)의 수로 모양을 정의할 수 있다. 변이 많을수록 정확하다.
- 변의 수가 경계 점 수와 같으면 각 점이 다각형의 정점이 되어 완벽하게 경계를 따른다.
- **최단 둘레 다각형(MPP)**: 경계가 수축할 수 있게 해 얻는 최소 둘레 다각형. 꼭짓점은 셀(회색 영역) 내부·외부 벽의 모퉁이들로 만들어진다.

| 단계 | 내용 |
|---|---|
| 점 집합 분석 | 주어진 점 집합을 분석해 다각형 생성의 기초 데이터 준비 |
| 다각형 생성 | 점들을 포함하며 둘레가 최소인 다각형 생성. 그리디 방법 또는 동적 계획법 사용 |
| 최적화 | 생성된 다각형의 둘레를 측정하고 더 짧은 둘레를 찾도록 반복 조정 |

## 4. 시그니처

- 2D 경계를 1D로 표현하는 방법이다. 경계의 특성을 간단히 표현할 때 쓴다.
- 예: 경계의 각 지점에서 중심까지의 거리 $r(\theta)$를 각도에 대한 함수로 그린다.

| 장점 | 단점 |
|---|---|
| 번역 불변: 시그니처가 이동해도 같은 서명 | 회전·스케일링 의존: 회전하거나 크기가 변하면 서명이 바뀜 |
| — | 볼록 영역에 대해서만 잘 정의됨. 비볼록 영역에서는 적용이 어려움 |

- 예: 정사각형은 $0 \le \theta \le \pi/4$에서 $r(\theta) = A\sec\theta$, $\pi/4 < \theta \le \pi/2$에서 $r(\theta) = A\csc\theta$가 $\pi/2$ 주기로 반복되는 패턴을 보인다.

## 5. 경계 특징 기술자

### 5.1 기본 경계 기술자

| 기술자 | 설명 |
|---|---|
| 길이 | 경계·윤곽선을 따라 측정한 거리 |
| 둘레 | 외곽선을 따라 측정한 전체 길이 |
| 장축 | 지름을 구성하는 두 극점을 연결하는 성분의 방향 |
| 단축 | 장축에 수직인 선 |
| 기본 사각형 | 두 축이 있는 경계의 외부 교차점 네 개를 통과하는 사각형 |
| 이심율 | 장축과 단축의 비 |
| 곡률 | 기울기의 변화율 |
| 오목/볼록 | 임의 점 $p$에서 기울기 변화가 음수이면 오목, 양수이면 볼록 |
| 직선 성분 | 영상·공간 안에서 직선 형태를 이루는 요소 |
| 모서리 | 기울기 변화가 90° ± 30°인 레이블 |

### 5.2 모양수

- **모양수**: 가장 작은 정수를 나타내는 체인 코드의 첫 번째 차이(first difference)다.
- 체인 코드의 차분은 인접 방향의 변화량이므로 회전에 불변이다. 시작점을 가장 작은 정수가 되게 정규화하면 시작점에도 불변이다.
- 모양수의 차수 $n$은 표현의 자릿수다. 4방향 체인 코드를 쓰면 폐쇄 경계에서 $n$은 짝수이고, $n$이 가능한 모양의 수를 제한한다.

| 차수 | 체인 코드 예 | 차분 | 모양수 |
|---|---|---|---|
| 4 | 0 3 2 1 | 3 3 3 3 | 3 3 3 3 |
| 6 | 0 0 3 2 2 1 | 3 0 3 3 0 3 | 0 3 3 0 3 3 |
| 8 | 0 0 3 3 2 2 1 1 | 3 0 3 0 3 0 3 0 | 0 3 0 3 0 3 0 3 |

### 5.3 푸리에 기술자

- $xy$ 평면의 $K$개 좌표쌍 $((x_0,y_0),(x_1,y_1),\dots,(x_{K-1},y_{K-1}))$을 복소 시퀀스로 본다.

$$
s(k) = x(k) + jy(k), \qquad k = 0,1,\dots,K-1
$$

$$
S(u) = \sum_{k=0}^{K-1} s(k)\,e^{-j2\pi uk/K}, \qquad u = 0,1,\dots,K-1
$$
$$
s(k) = \frac{1}{K}\sum_{u=0}^{K-1} S(u)\,e^{j2\pi uk/K}, \qquad k = 0,1,\dots,K-1
$$

- 저주파 계수 $P$개만 남겨 역변환하면 경계를 근사할 수 있다.

$$
\hat s(k) = \frac{1}{K}\sum_{u=0}^{P-1} S(u)\,e^{j2\pi uk/K}, \qquad k = 0,1,\dots,K-1
$$

- $P$가 작을수록 매끄러운 큰 형태만 남고, $P$가 클수록 세부가 살아난다. 사람 염색체 경계(2,868점)를 1,434·286·144·72·36·18·8개 기술자로 재구성하면 점점 단순해지지만 전체 윤곽은 유지된다.
- 푸리에 기술자는 시작점 이동(위상), 회전(계수 위상), 스케일(계수 크기)에 대한 성질을 이용해 정규화할 수 있다.

### 5.4 통계적 모멘트

- 경계 구간의 모양을 1차원 이산 함수 $g(r)$로 표현하고, $g(r_i)$를 $r_i$가 발생할 확률로 다룬다.

$$
m = \sum_{i=0}^{K-1} r_i\,g(r_i), \qquad \mu_n(r) = \sum_{i=0}^{K-1}(r_i - m)^n g(r_i)
$$

- $n$차 모멘트로 경계의 퍼짐(2차), 비대칭(3차), 뾰족함(4차)을 정량화한다.

## 6. 영역 특징 기술자

### 6.1 기본 기술자

| 기술자 | 설명 |
|---|---|
| Area | 영역의 픽셀 수 |
| Perimeter | 경계의 길이 |
| Compactness | 둘레²/면적 (원에 가까울수록 작음) |
| Mean and median gray levels | 평균·중앙값 밝기 |
| Min and max gray levels | 최소·최대 밝기 |
| Number of pixels above/below mean | 평균보다 높거나 낮은 픽셀 수 |

### 6.2 위상학적 기술자: 오일러 수

$$
E = C - H
$$

- $C$: 연결 성분 수, $H$: 홀 수.
- 예: 글자 A는 연결 성분 1개, 홀 1개로 $E = 0$. 글자 B는 연결 성분 1개, 홀 2개로 $E = -1$.

### 6.3 텍스처

- **텍스처**는 부드러움, 거침, 규칙성 같은 속성의 척도를 제공한다. 통계학적 접근과 스펙트럼 접근이 있다.

**(1) 통계학적 접근**

$$
m = \sum_{i=0}^{L-1} z_i p(z_i), \qquad \mu_n(z) = \sum_{i=0}^{L-1}(z_i - m)^n p(z_i)
$$

| 척도 | 식 | 의미 |
|---|---|---|
| 평균 | $m$ | 전체 밝기 수준 |
| 분산(2차 모멘트) | $\sigma^2 = \mu_2(z)$ | 밝기 퍼짐 |
| 부드러움 | $R(z) = 1 - \dfrac{1}{1+\sigma^2(z)}$ | 분산이 클수록 1에 가까움 |
| 왜도(3차 모멘트) | $\mu_3(z)$ | 분포의 비대칭 |
| 편평도(4차 모멘트) | $\mu_4(z) = \sum (z_i-m)^4 p(z_i)$ | 상대적 편평도 |
| 균일성 | $U(z) = \sum p^2(z_i)$ | 특정 밝기에 집중될수록 큼 |
| 엔트로피 | $e(z) = -\sum p(z_i)\log_2 p(z_i)$ | 무질서도 |

- 예: 초전도체 광학 현미경 영상(부드러움)은 표준편차 11.79, $R = 0.002$, 엔트로피 5.434, 콜레스테롤 영상(거침)은 표준편차 74.63, $R = 0.079$, 엔트로피 7.783, 마이크로프로세서 영상(규칙성)은 왜도 0.750으로 구분된다.

**(2) 스펙트럼 접근**

- 푸리에 스펙트럼에서 유용한 세 특징: 두드러진 피크(주요 방향), 피크의 위치(기본 공간 주기), 주기적 성분 제거 후의 비주기 요소(통계적 기술자로 처리).
- 극좌표 스펙트럼 $S(r,\theta)$에서 방향별 1차 함수 $S_\theta(r)$과 주파수별 1차 함수 $S_r(\theta)$를 합산해 전역 기술자를 만든다.

$$
S_r = \sum_{\theta=0}^{\pi} S_\theta(r), \qquad S_\theta = \sum_{r=1}^{R_0} S_r(\theta)
$$

- 랜덤하게 배치된 객체와 정렬된 객체의 스펙트럼을 비교하면, 정렬된 쪽은 방향에 따라 뾰족한 피크가 나타나 $S_\theta$ 그래프에서 방향성이 드러난다.

## 핵심 정리

- 경계선 추적은 8-이웃을 시계 방향으로 조사해 점 시퀀스를 만들고, 체인 코드는 방향 번호로 경계를 부호화한다.
- 시그니처는 2D 경계를 1D $r(\theta)$로 바꾸며 이동에 불변, 회전·스케일에 의존하고 볼록 영역에 적합하다.
- 푸리에 기술자는 저주파 계수만으로 경계를 근사하고, 모양수는 체인 코드 차분으로 회전·시작점 불변 기술자를 만든다.
- 영역 기술자는 면적·둘레·컴팩트니스, 오일러 수 $E = C-H$, 통계·스펙트럼 텍스처 척도로 구성된다.
