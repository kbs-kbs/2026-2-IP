# 1차시 디지털 영상처리란?

## 1. 정의

- **디지털 영상처리**: 디지털 컴퓨터로 디지털 영상을 처리하는 것.
- 대상이 되는 영상의 범위는 인간의 시각으로 보이는 범위를 넘어선다. 초음파, 전자현미경, 컴퓨터 생성 영상처럼 다양한 소스에서 만들어진 영상을 모두 포함한다.
- 영상처리는 영상 처리 전반을 아우르는 폭넓은 개념의 기술이다.

### 영상의 수학적 정의

- **영상**: 2차원 함수 $f(x, y)$로 정의한다. $x, y$는 공간 좌표이고, 그 순서쌍에서의 진폭 $f$가 **밝기(그레이 레벨)**이다.
- **디지털 영상**: 진폭 $f$가 유한하고 이산적인 수량인 영상. 즉 연속 함수 $f(x,y)$를 공간과 밝기 양쪽에서 이산화한 것이다.
- **디지털 영상처리**: 이렇게 이산화된 영상을 디지털 컴퓨터로 처리하는 것.

## 2. 영상처리 분야의 구분

| 분야 | 목표 | 입출력 |
|---|---|---|
| 영상처리 | 영상 획득·개선·복원을 통해 영상 분석에 쓸 출력을 만든다 | 영상 → 영상 |
| 영상분석 | 처리된 영상의 의미를 파악한다. 컴퓨터 비전과 영상처리의 중간 위치 | 영상 → 속성 |
| 컴퓨터 비전 | 컴퓨터로 인간 시각을 흉내 낸다 | 영상 → 해석·판단 |

## 3. 영상처리 레벨

| 레벨 | 하는 일 | 입력 → 출력 | 예 |
|---|---|---|---|
| 저수준 처리 | 노이즈 제거, 콘트라스트 개선, 영상 선명화 | 영상 → 영상 | 텍스트 영상을 획득해 개선 |
| 중수준 처리 | 영상 분할·구획화, 컴퓨터 처리가 가능하도록 묘사·분류 | 영상 → 속성(에지, 윤곽, 객체) | 에지 검출, 영역 분할 |
| 고수준 처리 | 인식된 객체의 의미 파악, 시각과 관련된 인지 기능 수행 | 속성·객체 → 의미 | 영상 분석, 장면 이해 |

- 저수준 처리는 노이즈 제거나 명암 처리로 영상을 눈에 보이게 개선하는 단계이고, 고수준으로 갈수록 각 영역이 갖는 의미를 파악해 전달하는 쪽으로 옮겨 간다.

## 4. 사용 분야

### 4.1 전자기(EM) 에너지 스펙트럼

- 영상의 주요 에너지원은 전자기 스펙트럼이다. 소스에 따라 X선, 가시선, 적외선 영상 등으로 나뉘고, 에너지원에 따라 음파·초음파·전자파 영상으로도 나뉜다.
- 스펙트럼은 광자당 에너지 순으로 배열된다. 감마선 → X선 → 자외선 → 가시광 → 적외선 → 마이크로파 → 라디오파 순으로 파장이 길어지고, 주파수와 에너지는 낮아진다.

| 대역 | 원리 | 대표 응용 |
|---|---|---|
| 감마선 | 방사성 동위원소 붕괴 시 방출되는 감마선을 이용 | 핵의학(골격 스캔), 천체 관찰(초신성·펄사·블레이자) |
| X선 | 가장 오래된 EM 방사 소스 중 하나, 투과 후 흡수 차이를 영상화 | 의료(디지털 방사선 사진, CT), 산업(회로 기판 부품 결함 검출), 천문학 |
| 자외선 | 형광 물질이 UV를 받아 가시광을 방출하는 현상 이용 | 석판술, 산업용 검사, 현미경 검사, 레이저, 생물학 영상, 지문 검출 |
| 가시광·적외선 | 인간이 가장 익숙하고 응용 범위가 넓은 대역 | 광학 현미경, 원격 감지(LANDSAT), 자동화된 제품 검사, 번호판 인식 |
| 마이크로파 | 레이더. 스스로 조명을 제공하고 구름·식물·얼음·모래를 투과 | 기상 관측, 위성 영상 레이더(SAR) |
| 라디오파 | 강한 자기장 속에서 짧은 라디오파 펄스를 통과시켜 공명 신호를 영상화 | MRI, 천체 영상 분석 |

- 형광 검사 원리: UV 광선이 형광 물질 원자와 충돌하면 전자가 높은 에너지 준위로 들뜨고, 들뜬 전자가 낮은 준위로 내려오면서 가시광 영역의 광자를 방출한다.
- 적외선 원격 감지에서 대역은 용도가 정해져 있다. 예를 들어 LANDSAT 계열의 MSS/TM 대역은 가시 청색(0.45~0.52 μm, 최대 수분 투과력), 가시 녹색(0.53~0.61 μm, 식물 생장력 측정), 가시 적색(0.63~0.69 μm, 식물 구별), 근적외선(0.78~0.90 μm, 생물량·해안선), 중적외선(1.55~1.75 μm, 토양·식물 수분), 열적외선(10.4~12.5 μm, 토양 수분·열지도), 단파장 적외선(2.09~2.35 μm, 광물 지도)에 쓴다.

### 4.2 그 밖의 영상화

| 구분 | 내용 |
|---|---|
| 소리 | 지질학 탐사(수백 Hz 소리 스펙트럼, 광물·석유 탐사), 초음파 영상(반사 정도 차이를 이미지화), 전송 전파 현미경 |
| 컴퓨터 생성 | 프랙털(수학적 규칙으로 기본 패턴 반복), 3D 모델링(영상처리와 컴퓨터 그래픽의 교집합, 의료 훈련·법의학·특수효과) |
| 방송·영화 | 디지털 영상 합성(두 개 이상 영상을 모아 새 영상 생성), 모핑(한 영상을 다른 영상으로 변환) |
| 의료 | X선, 초음파, MRI, CT 등 인체 영상으로 정밀 진찰 |
| 산업 자동화 | 머신 비전: 산업용 카메라로 제품 품질 검사·모니터링 |
| 보안 | 생체 인식(지문·홍채·혈관·얼굴), 디지털 워터마킹(보이지 않는 표시로 인증) |

## 핵심 정리

- 디지털 영상은 $f(x,y)$의 공간·진폭 이산화로 정의되고, 영상처리는 그 영상을 컴퓨터로 다루는 기술 전반을 뜻한다.
- 저수준(영상→영상), 중수준(영상→속성), 고수준(속성→의미)의 세 층으로 처리 수준을 나눈다.
- 응용은 감마선부터 라디오파까지 EM 대역별 특성에 따라 갈리고, 소리·컴퓨터 생성·합성·의료·산업·보안 분야로 확장된다.
