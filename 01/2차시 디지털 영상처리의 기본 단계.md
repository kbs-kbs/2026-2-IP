# 2차시 디지털 영상처리의 기본 단계

## 1. 영상처리 프로세스 다이어그램

영상처리 시스템은 다음 모듈이 지식 베이스와 연결된 파이프라인으로 표현된다.

```
영상 획득 → 영상 개선 → 영상 복원 → 컬러 영상 처리 → 영상 변환
        → 영상 분할 → 형태학적 처리 → 영상 압축
        → 특징 추출 → 패턴 분류
```

- 각 단계는 필요에 따라 지식 베이스의 도움을 받고, 지식 베이스는 문제 도메인 지식을 코드화한 것이다.
- 처리 작업의 복잡도가 커질수록 관여하는 처리 과정도 늘어난다. 관심 정보가 있을 것으로 알려진 영상 영역을 미리 열거해 두면 탐색 범위를 줄여 작업을 단순화할 수 있다.

## 2. 단계별 계통화

| 단계 | 정의 | 주요 내용 |
|---|---|---|
| 영상 획득 | 아날로그·센서·디지털 등 다양한 소스에서 영상을 얻는다 | 일반적으로 스케일링 같은 전처리 포함 |
| 영상 개선 | 특정 운용에 더 적합하도록 영상을 조작한다 | 범용 이론이 없고 관찰자 경험에 크게 의존. 평활화, 샤프닝, 잡음 제어 |
| 영상 복원 | 훼손·오류로 왜곡된 영상을 원래에 가장 가까운 형태로 되돌린다 | 영상 품질 저하에 대한 수학적·확률적 모델에 기반한 객관적 복구 |
| 컬러 영상 처리 | 컬러 모델과 디지털 도메인의 컬러 처리 기술을 다룬다 | 인터넷 영상 처리 증가로 중요도 상승 |
| 영상 변환 | 영상을 다른 형태의 데이터로 변환한다 | 푸리에 변환, 이산 코사인 변환, 웨이블릿 변환 |
| 영상 압축 | 저장 장치와 전송 대역폭을 줄인다 | 무손실 기법, 손실 기법 |
| 형태학적 처리 | 모양의 표현·묘사에 유용한 성분을 추출한다 | 영상을 출력하는 처리에서 영상 속성을 출력하는 처리로 전환되는 단계 |
| 영상 분할 | 영상을 구성 요소·객체로 구획화한다 | 분할이 정확할수록 인식 성공률이 높다 |
| 특징 추출 | 특징을 찾고 정량적 속성을 부여한다 | 특징 검출(예: 모서리 검출), 특징 기술(예: "왼쪽 아래 모서리") |
| 패턴 분류 | 특징 기술자를 기반으로 객체에 레이블을 할당한다 | 최소 거리, 상관관계, 베이즈 분류기, DNN 등 |

### 영상 개선과 영상 복원의 차이

| 구분 | 영상 개선 | 영상 복원 |
|---|---|---|
| 목적 | 특정 운용에 적합하게 보기 좋게 만든다 | 열화 원인을 모델로 삼아 원영상에 가깝게 되돌린다 |
| 기준 | 관찰자의 주관적 선호 | 수학적·확률적 열화 모델 |
| 예 | 평활화(노이즈·미세 구조를 배제하고 중요한 패턴 포착), 샤프닝, 잡음 제어 | 블러·잡음 모델의 역문제 해법 |

### 영상 변환의 세 가지

| 변환 | 특징 |
|---|---|
| 푸리에 변환 | 시간·공간 함수를 시간·공간 주파수 성분으로 분해. 원영상 → 주파수 영상 → 역변환으로 복원 |
| 이산 코사인 변환 | 이산 푸리에 변환과 유사하지만 결과가 실수로만 나와 처리가 간단하다 |
| 웨이블릿 변환 | 다중 해상도 분해에 쓰인다 |

### 영상 압축

- **무손실 기법**: 압축 후 복원해도 원본과 차이가 없다.
- **손실 기법**: 원본 대비 품질이 저하된다. 손실률이 커질수록 화질 열화가 두드러진다.

## 3. 영상처리 시스템의 구성 요소

| 구성 요소 | 역할 |
|---|---|
| 영상 센서 | 객체에서 방사되는 에너지에 민감한 물리적 감지 장치 |
| 디지타이저 | 감지 장치의 출력을 디지털 형태로 변환 |
| 영상처리 전용 하드웨어 | 전체 영상에 대해 병렬로 산술·논리 연산 수행(예: ALU). 빠른 영상 평균화로 노이즈 축소 |
| 컴퓨터 | 범용 컴퓨터(PC~슈퍼컴퓨터) |
| 영상처리 소프트웨어 | 특정 작업을 수행하는 특화 모듈(예: MATLAB Image Processing Toolbox) |
| 대용량 저장소 | 단기 저장, 온라인 저장, 아카이브 저장 |
| 영상 표시기 / 하드카피 | 컬러 모니터, 프린터·필름 등 |
| 네트워크 / 클라우드 | 영상 전송, 대역폭이 중요한 요인 |

### 하드웨어 발전

- 1980년대~1990년대 초반: 소형화된 범용 소형 컴퓨터와 특수 영상처리 하드웨어의 조합, 단일 보드 형태의 영상처리 하드웨어.
- 1990년대 말~2000년대 초반: GPU 형태의 애드온 보드 도입.

### 저장소의 세 층

| 계층 | 매체 | 특징 |
|---|---|---|
| 단기 저장 | 컴퓨터 메모리, 프레임 버퍼 | 처리 중 사용. 프레임 버퍼는 한 개 이상 영상을 비디오 속도로 접근하며 스크롤·팬·줌이 가능한 특수 보드 |
| 온라인 저장 | 자기 디스크, 광학 매체 | 잦은 접근, 상대적으로 빠른 호출 |
| 아카이브 저장 | 자기 테이프, 광학 디스크 | 대용량, 드문 접근 |

- 하드카피 중 해상도가 가장 높은 매체는 필름이고, 서류 소재로는 종이가 최선이다.

## 4. 시각적 인지 요소

### 4.1 눈의 구조

| 부위 | 역할 |
|---|---|
| 각막 | 눈 앞표면을 덮는 질기고 투명한 조직 |
| 홍채 | 눈으로 들어오는 광량 제어 |
| 수정체 | 망막에 상을 맺히게 함 |
| 망막 | 초점이 맞을 때 외부 객체의 상이 비추는 곳 |
| 맹점 | 시각 신경 섬유가 모이는 곳. 시각 세포가 없어 반응이 없다 |

- 망막에는 간상체와 추상체가 분포하며, 중심와에는 추상체가 밀집하고 맹점 부근에는 간상체가 많다.

### 4.2 눈의 영상 형성 (얇은 렌즈 근사)

수정체 두께가 얇으면 먼 객체, 두꺼우면 가까운 객체를 인지한다. 수정체 중심과 망막 사이 거리는 약 17 mm이다.

거리 $D$에 있는 높이 $H$인 물체가 망막에 맺히는 상 높이 $h$는 닮은꼴로 구한다.

$$
\frac{H}{D} = \frac{h}{17\ \text{mm}} \quad\Rightarrow\quad h = 17 \times \frac{H}{D}
$$

예: 100 m 거리의 15 m 나무는 $h = 17 \times 15/100 = 2.55\ \text{mm}$ (교안 표기 2.5 mm)로 맺힌다.

### 4.3 밝기 적응과 주관적 밝기

- 주관적 밝기는 눈에 입사되는 빛 세기의 **로그 함수**에 가깝다.
- **명소시(photopic vision)**: 휘도 약 2 nit 이상에서 색과 모양이 선명하게 보이는 상태.
- **암소시(scotopic vision)**: 휘도 약 0.001 nit 이하에서 명암만 흐릿하게 보이는 상태.
- 시각 체계는 명소시와 암소시를 동시에 수행할 수 없으므로 전체 감도를 바꿔 적응한다. 어떤 조건에서의 현재 감도 수준을 **밝기 적응 레벨** $B_a$라 하고, 그때 지각 가능한 주관적 밝기 범위를 $B_b$라 한다.

### 4.4 착시와 밝기 지각

| 현상 | 내용 |
|---|---|
| 마흐 밴드 | 밝기가 다른 경계에서 실제보다 강한 밝기 패턴을 지각한다. 밝기 인식이 단순 함수가 아님을 보여 준다 |
| 동시 콘트라스트 | 같은 밝기의 안쪽 사각형도 주변이 어두울수록 더 밝게 보인다 |
| 착시 | 없는 정보를 채우거나 기하 특징을 잘못 인지한다(존재하지 않는 사각형·원, 평행으로 보이지 않는 평행선 등) |

## 핵심 정리

- 영상처리 파이프라인은 획득 → 개선 → 복원 → 컬러 처리 → 변환 → 분할 → 형태학 → 압축 → 특징 추출 → 패턴 분류로 계통화된다.
- 개선은 주관적, 복원은 열화 모델에 기반한 객관적 처리라는 점이 구분점이다.
- 시스템은 센서·디지타이저·전용 하드웨어·소프트웨어·저장소·출력 장치·네트워크로 구성되고, 인간 시각계의 로그 감도·밝기 적응·착시는 영상 개선과 평가의 전제가 된다.
