# 1차시 영상 압축의 기본

## 1. 영상 압축과 데이터 중복성

- **데이터 압축**: 주어진 정보량을 표현하는 데 필요한 데이터 양을 줄이는 과정. 같은 정보를 표현하는 데 다양한 양의 데이터가 쓰이므로, 무의미하거나 반복된 정보를 담은 표현은 중복성을 갖는다.
- 상대적 중복성과 압축률:

$$
C = \frac{b}{b'}, \qquad R = 1 - \frac{1}{C}
$$

- $b$: 원본 데이터 비트 수, $b'$: 압축 데이터 비트 수. $b = b'$이면 $C = 1$, $R = 0$으로 중복이 없다.

### 1.1 데이터 중복성의 세 유형

| 유형 | 원인 | 대응 |
|---|---|---|
| 코딩 중복성 | 2D 밝기 배열을 표현하는 8비트 코드가 필요한 것보다 많은 비트를 포함 | 가변 길이 코딩(허프만 등) |
| 공간·시간 중복성 | 픽셀이 공간·시간적으로 상관되어 정보가 불필요하게 중복 | 예측 코딩, 변환 코딩 |
| 무의미한 정보(심리 시각적 중복) | 인간 시각 체계가 무시하거나 용도와 무관한 정보 | 양자화(비가역) |

### 1.2 코딩 중복성의 정량화

$[0, L-1]$ 구간의 이산 랜덤 변수 $r_k$가 $M \times N$ 영상의 밝기를 표현하고 $r_k$의 확률이 $p_r(r_k)$일 때

$$
p_r(r_k) = \frac{n_k}{MN}
$$
$$
L_{avg} = \sum_{k=0}^{L-1} l(r_k)\,p_r(r_k)
$$
$$
\text{총 비트 수} = M \times N \times L_{avg}
$$

- $l(r_k)$: 레벨 $r_k$를 표현하는 코드 길이. 자연 m비트 고정 길이 코딩이면 $L_{avg} = m$, $l(r_k) = m$이다.
- 코드 길이를 확률에 따라 달리하면 $L_{avg} < m$이 되어 코딩 중복성이 제거된다.

### 1.3 공간·시간 중복성

- 대부분 영상에서 픽셀은 $x$, $y$ 방향 모두 그리고 시간적으로 서로 연관된다.
- 대부분의 픽셀 밝기가 이웃 밝기로부터 어느 정도 예측되므로 단일 픽셀이 운반하는 정보는 작다.
- 중복을 없애려면 연속 길이(run length), 인접 픽셀 간 차이 같은 비시각적 표현으로 변환한다.

### 1.4 무의미한 정보와 양자화

- 인간 시각 체계에 무시되거나 의도된 용도와 무관한 정보는 제거 대상이다. 제거 과정이 **양자화**이며 정보가 손실되므로 비가역 연산이다.

| 구분 | 조건 |
|---|---|
| 가역 | 변환된 데이터 집합에서 원래 2D 밝기 배열의 픽셀이 오차 없이 복구됨 |
| 비가역 | 가역적 복구가 되지 않음 |

## 2. 손실 압축과 무오류 압축

### 2.1 영상 정보 측정

- 사건 $E$의 정보량과 소스 엔트로피:

$$
I_E = \log\frac{1}{P(E)} = -\log P(E)
$$
$$
H = -\sum_{j=1}^{J} P(a_j)\log P(a_j)
$$

- 엔트로피는 소스 출력당 평균 정보량으로, 무손실 압축의 이론적 하한을 준다.

### 2.2 충실도 기준

| 기준 | 내용 |
|---|---|
| 객관적 충실도 | 정보 손실이 압축 입출력의 수학적 함수로 표현됨. 예: RMS 오차 |

$$
e(x,y) = f(x,y) - \hat{f}(x,y)
$$

- **주관적 충실도**: 압축 해제 영상을 사람이 보고 화질을 평가한다.

### 2.3 영상 압축 모델

- 인코더(압축)와 디코더(압축 해제)로 구성된다. $\hat{f}(x,y) = f(x,y)$이면 무오차·무손실·정보 보존적이고, 아니면 손실성이다.

| 단계 | 역할 | 가역성 |
|---|---|---|
| 매퍼(mapper) | $f(x,y)$를 공간·시간 중복이 감소하는 포맷으로 변환 | 가역 |
| 양자화기 | 충실도 기준에 맞춰 매퍼 출력의 정밀도를 낮춤 | 비가역 |
| 기호 인코더 | 양자화기 출력을 고정·가변 길이 코드로 생성 | 가역 |
| 기호 디코더·역매퍼 | 기호 인코더와 매퍼의 역연산 | — |

- 손실은 양자화기에서만 발생한다. 나머지 단계는 무손실이다.

### 2.4 포맷, 컨테이너, 표준

| 구분 | 정의 |
|---|---|
| 영상 파일 포맷 | 영상 데이터를 체계화하고 저장하는 표준 방법. 데이터 정리와 압축 유형을 정의 |
| 영상 컨테이너 | 파일 포맷과 유사하지만 여러 종류의 영상 데이터를 다룸 |
| 압축 표준 | 영상 압축·해제 절차를 정의 |

- 구분 예: 정지영상(JPEG, JPEG-LS, JPEG-2000, PNG, TIFF, WebP, GIF, BMP, PDF), 비디오(MPEG-1/2/4, H.261~H.265, DV, AVS, HDV, M-JPEG, QuickTime, VC-1/WMV9, WebP VP8), 이진(CCITT Group3/4, JBIG, JBIG2, TIFF), 연속 톤(JPEG 계열).

## 3. 허프만 코딩과 골롬 코딩

### 3.1 허프만 코딩

- 코딩 중복성을 제거하는 데 가장 많이 쓰이는 기법이다. 정보 소스의 기호를 개별적으로 코딩하고, 소스 기호당 코드 기호 수를 가장 적게 산출한다.
- **소스 기호를 한 번에 하나씩 코딩한다는 조건**에서 고정값 $n$에 대한 산출 코드가 최적이다.

**코딩 단계**

1. 대상 기호들을 확률 순으로 정렬한다.
2. 가장 낮은 확률의 기호 두 개를 결합해 다음 소스 축소에서 하나의 기호로 대신한다. 이를 반복해 확률 1의 소스까지 축소한다.
3. 가장 작은 소스부터 원래 소스로 돌아가며 각 축소 소스를 코딩한다.

| 기호 | 확률 | 코드 |
|---|---|---|
| a2 | 0.4 | 1 |
| a6 | 0.3 | 00 |
| a1 | 0.1 | 011 |
| a4 | 0.1 | 0100 |
| a3 | 0.06 | 01010 |
| a5 | 0.04 | 01011 |

- 평균 코드 길이 $= 0.4(1) + 0.3(2) + 0.1(3) + 0.1(4) + 0.06(5) + 0.04(5) = 2.3$비트로, 고정 3비트보다 짧다.
- 어느 코드도 다른 코드의 접두부가 되지 않는 **접두부호**이므로 구분자 없이 복호할 수 있다.

### 3.2 골롬 코딩

- 지수적으로 감소하는 확률 분포를 갖는 음이 아닌 정수 입력에 대한 코딩이다. 허프만 코드보다 계산이 간단한 코드 집합으로 최적으로 인코딩한다.
- 골롬 코드 $G_m(n)$은 몫 $\lfloor n/m \rfloor$의 일진 코드와 나머지 $n \bmod m$의 이진 표현을 조합한다.

**절차**

1. 몫 $q = \lfloor n/m \rfloor$의 일진 코드를 만든다(정수 $q$의 일진 코드는 $q$개의 1 뒤에 0).
2. $k = \lceil \log_2 m \rceil$, $c = 2^k - m$, $r = n \bmod m$에서
   - $0 \le r < c$이면 $r$을 $k-1$비트로 절단,
   - 그 외는 $r$을 $k$비트로 절단.
3. 1과 2의 결과를 결합한다.

| $n$ | $G_1(n)$ | $G_2(n)$ | $G_4(n)$ | $G_0^{exp}(n)$ |
|---|---|---|---|---|
| 0 | 0 | 00 | 000 | 0 |
| 1 | 10 | 01 | 001 | 100 |
| 2 | 110 | 110 | 010 | 101 |
| 3 | 1110 | 101 | 011 | 11000 |
| 4 | 11110 | 1100 | 1000 | 11001 |
| 5 | 111110 | 1101 | 1001 | 11010 |
| 6 | 1111110 | 11100 | 1010 | 11011 |
| 7 | 11111110 | 11101 | 1011 | 1110000 |
| 8 | 111111110 | 111100 | 11000 | 1110001 |
| 9 | 1111111110 | 111101 | 11001 | 1110010 |

- 지수 골롬 $G_0^{exp}$ 예: $n=8$ → $k=0$, $I = \lfloor\log_2 9\rfloor = 3$, $7 \le 8 < 15$이므로 몫 3의 일진 코드 1110, 나머지 $8-(2^0+2^1+2^2)=1$을 3비트로 절단한 001을 붙여 1110001.

## 핵심 정리

- 압축은 코딩·공간시간·심리시각 세 중복을 줄이는 일이고, $C = b/b'$, $R = 1-1/C$로 측정한다.
- 압축 모델은 매퍼–양자화기–기호 인코더 구조이며 손실은 양자화기에서만 생긴다.
- 허프만은 기호별 최적 접두부호를 만들고, 골롬은 기하 분포 정수에 대해 몫의 일진 코드와 나머지 이진 코드를 조합한다.
